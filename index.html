Pair with your TV

Connecting to samsung.lan…

  1. Make sure the TV is on and on the same network.
  2. When the TV shows a Smart Device / Allow prompt, select Allow.
  3. No prompt? Turn on Settings → General → External Device Manager → Device Connection Manager → Access Notification on the TV.
  4. This page connects automatically and saves the token.

Keyboard capture

Turn on Keyboard capture, then use these keys. Ctrl+Shift+K releases capture.

↑ ↓ ← →navigate EnterOK / select Backspacedelete text Escback HomeHome Page Up / Page Downchannel up / down + / −volume up / down Mmute Spacetype a space 0–9type digits Iinfo Ssource Gguide

Letters, digits and punctuation are typed into the focused TV text field. Use the on-screen D-pad or arrow keys for navigation; the on-screen buttons still send media/volume keys.

Send text to TV

Focus the TV's search or text field first, then send. The TV receives the string via the remote-control channel.

Tip: turn on Keyboard capture afterwards to use arrows and Enter in the app.
